What Is a Quadratic Function?

Objective: Define the quadratic function

Definition

A quadratic function is a polynomial function that can be written in the form

General (polynomial) formf(x) = ax² + bx + c,   where a ≠ 0

The constants a, b, and c are real numbers called coefficients. The requirement a ≠ 0 is essential — if a = 0, the x² term disappears and the function is no longer quadratic.

  • Leading coefficient: a — it controls the direction and width of the graph.
  • Degree: the highest power of x is exactly 2.
  • Graph: every quadratic function graphs as a U-shaped curve called a parabola.
  • Domain: all real numbers, (−∞, ∞) — you may plug in any x.

Example 1 — Identify the coefficients

For f(x) = −3x² + 7x − 2:   a = −3, b = 7, c = −2. Since a < 0, its parabola opens downward.

For g(x) = x² − 9:   a = 1, b = 0, c = −9. (A missing term just means its coefficient is 0.)

Two forms you must know

General form: f(x) = ax² + bx + c → great for finding the y-intercept (it's just c).

Standard (vertex) form: f(x) = a(x − h)² + k → great for reading the vertex (h, k) directly.

Both describe the same parabola — Section 3 shows how to convert between them.

Meet the family of parabolas

The sign of a decides whether the parabola opens up (∪, has a lowest point) or down (∩, has a highest point). The size of |a| decides its width.

y = x² (a = 1) y = 0.4x² (wider: |a| < 1) y = −x² + 4 (opens down: a < 0)
No. Its highest power is 4, so it is a quartic (degree-4) polynomial. A quadratic must have degree exactly 2 — the x² term must be the highest power present.

Graphing by Transforming the Parent f(x) = x²

Objective: Graph a quadratic function through transformations of f(x) = x²

The simplest quadratic function, f(x) = x², is called the parent function. Its graph is a parabola with vertex at the origin, opening upward. Every other quadratic function is the parent after a sequence of transformations:

Standard (transformation) formf(x) = a(x − h)² + k
PieceEffect on the graph of x²
+ k outsideShift up k units (down if k is negative) → moves the vertex vertically
(x − h) insideShift right h units — opposite of what it looks like! (x+4)² shifts left 4
a < 0Reflect across the x-axis (opens downward)
|a| > 1Vertical stretch — parabola looks narrower
0 < |a| < 1Vertical compression — parabola looks wider

The point (h, k) is the vertex, and the vertical line x = h is the axis of symmetry.

From General Form to Standard Form

Objective: Convert ax² + bx + c into a(x − h)² + k by completing the square

To convert f(x) = ax² + bx + c into standard form we use a technique called completing the square. The goal: create a perfect square trinomial x² + px + (p/2)², which factors as (x + p/2)².

The recipe

  1. Factor a out of the x² and x terms only.
  2. Take half of the x-coefficient inside the parentheses, then square it.
  3. Add and subtract that number inside (net change = 0 — legal!).
  4. Factor the perfect square; distribute a to the subtracted term.
  5. Combine constants → you now have a(x − h)² + k.

Example 3 — Worked by hand

Convert f(x) = 2x² + 12x + 7 to standard form:

f(x) = 2(x² + 6x) + 7   (factor 2 from x-terms)

half of 6 = 3, and 3² = 9

f(x) = 2(x² + 6x + 9 − 9) + 7

f(x) = 2((x + 3)² − 9) + 7

f(x) = 2(x + 3)² − 18 + 7

f(x) = 2(x + 3)² − 11  → vertex (−3, −11)

Vertex & Axis of Symmetry

Objective: Find the vertex and axis of symmetry of a quadratic function

Key vocabulary

The vertex is the turning point of the parabola — its lowest point if it opens up, its highest point if it opens down. The axis of symmetry is the vertical line through the vertex that folds the parabola onto itself.

From general form f(x) = ax² + bx + c Axis of symmetry:  x = −b / (2a)     Vertex:  ( h, f(h) ) where h = −b / (2a)
From standard form f(x) = a(x − h)² + k Vertex = (h, k)   ·   Axis: x = h   (just read them off!)

Example 4 — From general form

Find the vertex and axis of f(x) = 3x² − 12x + 1.

  1. a = 3, b = −12 → h = −b/(2a) = 12/6 = 2. Axis: x = 2.
  2. k = f(2) = 3(4) − 12(2) + 1 = 12 − 24 + 1 = −11.
  3. Vertex = (2, −11). Since a = 3 > 0, this is the minimum point.

Example 5 — From standard form

For f(x) = −2(x + 1)² + 8: vertex = (−1, 8), axis = x = −1, opens downward, so 8 is the maximum value.

h = −2/(2·1) = −1. k = f(−1) = 1 − 2 − 8 = −9. Vertex (−1, −9), axis x = −1, opens up → minimum value −9.

Finding the Intercepts

Objective: Find the x- and y-intercepts of a quadratic function

y-intercept (always exactly one)

Set x = 0:  f(0) = a·0 + b·0 + c = c.

The y-intercept is always (0, c). In general form it is literally the constant term.

x-intercepts (0, 1, or 2)

Set f(x) = 0 and solve ax² + bx + c = 0 by factoring or the Quadratic Formula:

x = ( −b ± √(b² − 4ac) ) / (2a)

The discriminant Δ = b² − 4ac tells you how many x-intercepts to expect

Δ > 0 → two x-intercepts · Δ = 0 → one (vertex touches the axis) · Δ < 0 → none (parabola never reaches the x-axis).

Δ > 0 : two interceptsy = x² − 4 → x = ±2
Δ = 0 : one intercepty = (x−2)² → x = 2
Δ < 0 : no interceptsy = x² + 3

Example 6 — Intercepts of f(x) = x² − 5x + 6

  • y-intercept: c = 6 → (0, 6).
  • x-intercepts: 0 = x² − 5x + 6 = (x − 2)(x − 3) → (2, 0) and (3, 0).
  • Check: Δ = 25 − 24 = 1 > 0 → two intercepts, as expected.

Example 7 — When factoring fails, use the formula

For f(x) = x² + 4x + 7: Δ = 16 − 28 = −12 < 0 → no x-intercepts. The whole parabola floats above the x-axis.

y-intercept: (0, −8). x-intercepts: 0 = (x + 4)(x − 2) → (−4, 0) and (2, 0).

Graphing with Vertex, Axis & Intercepts

Objective: Graph a quadratic function using its key features

The 5-step graphing strategy

  1. Direction: a > 0 opens up ∪; a < 0 opens down ∩.
  2. Axis of symmetry: compute x = −b/(2a).
  3. Vertex: evaluate f at that x → plot (h, k).
  4. Intercepts: plot y-int (0, c); solve f(x) = 0 for x-ints (if any).
  5. Reflect & connect: mirror points across the axis using symmetry, then draw a smooth parabola.

Example 8 — Full walkthrough: f(x) = x² − 4x − 5

  1. a = 1 > 0 → opens upward.
  2. Axis: x = −(−4)/(2·1) = 2.
  3. Vertex: f(2) = 4 − 8 − 5 = −9 → (2, −9).
  4. y-int: (0, −5). x-ints: 0 = (x − 5)(x + 1) → (−1, 0), (5, 0).
  5. Notice (0, −5) reflects across x = 2 to the point (4, −5). Connect smoothly.

🧭 Reading the table like a mathematician

  • The highlighted gold row is the vertex — the turning point.
  • y-values decrease toward the vertex when a > 0, then increase again (increase → decrease when a < 0).
  • The y-values change by odd multiples of a as you move one step at a time (for step 1: differences grow by 2a each row) — a signature of quadratics.
  • Two equal y-values in different rows? Their x-values average to h — you've found the axis of symmetry from data alone!

Maximum & Minimum Applications

Objective: Solve applications requiring a maximum or minimum value

The big idea

The vertex is where a quadratic reaches its extreme value:

  • a > 0 → parabola opens up → vertex is the minimum; minimum value = k = f(h).
  • a < 0 → parabola opens down → vertex is the maximum; maximum value = k = f(h).

Remember: h tells you WHEN/WHERE it happens; k tells you HOW MUCH. Read the question carefully!

Strategy for word problems

  1. Identify the quantity to maximize/minimize and write it as a quadratic in one variable.
  2. Check the sign of a to confirm you really have a max (a < 0) or min (a > 0).
  3. Compute h = −b/(2a) → the optimal input.
  4. Evaluate f(h) → the optimal value. Answer the actual question asked, with units.

Example 9 — The river fencing problem

A farmer has 200 ft of fencing to enclose three sides of a rectangular pen (the river forms the fourth side). What dimensions maximize the area?

  1. If each width is x, the length is 200 − 2x. Area: A(x) = x(200 − 2x) = −2x² + 200x.
  2. a = −2 < 0 → the vertex is a maximum. ✔
  3. x = −b/(2a) = −200/(2·(−2)) = 50 ft.
  4. Length = 200 − 2(50) = 100 ft. Maximum area = A(50) = 50·100 = 5000 ft².

Example 10 — Projectile motion

A ball is thrown upward from a height of 80 ft with initial velocity 64 ft/s: h(t) = −16t² + 64t + 80.

  1. a = −16 < 0 → vertex = maximum height.
  2. Time of max height: t = −64/(2·(−16)) = 2 seconds.
  3. Max height: h(2) = −16(4) + 64(2) + 80 = −64 + 128 + 80 = 144 ft.

(c = 80 is the starting height — the y-intercept has physical meaning too!)

a = 4 > 0 → minimum. h = 16/8 = 2; f(2) = 16 − 32 + 9 = −7. Minimum value −7 at x = 2.
